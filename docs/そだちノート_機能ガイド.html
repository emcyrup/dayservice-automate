ABOUT / できること

そだちノートとは

毎日の記録、保護者への報告、個別支援計画、加算の点検、そして出欠実績から国保連への請求まで。 放課後等デイサービスの事務作業を、1つのアプリでまとめて引き受けます。他の記録ソフト・請求ソフトと使い分ける必要はありません。

⏱️
残業を減らす
記録・報告文の作成時間を大幅に短縮。閉所後の書類残業から解放。
💰
お金を守る
加算の算定漏れ・減算・返戻のリスクをAIが事前に点検。
🗂️
二重入力をなくす
記録がそのまま実績になり、請求データまでつながる。転記ゼロ。
FEATURES / 主な機能

6つの機能

1
貯めて、ひと押しで活動記録毎日
活動中に浮かんだことを、キーワードで送るか音声で話しておくだけ。閉所後に「生成」を押せば、AIが活動記録の形（活動内容・様子・支援のねらい・引き継ぎ）に整えます。
使い方　💬記録タブで児童を選ぶ → その場でキーワードを送る（または🎤で話す）→ 帰りに「貯めたメモから生成」→ 内容を確認して保存。
2
保護者への報告文を自動生成毎日
その日の記録から、保護者向けのやわらかい報告文をワンタップで作成。トーン（ていねい／あたたかめ／簡潔）も選べます。
使い方　✉️報告タブで記録を選ぶ → トーンを選ぶ → 生成 → 必ず内容を確認・編集してから送信。
🌱 そだちノート サービスガイド2
3
個別支援計画・活動計画の下書き半年ごと
これまでの記録の蓄積を根拠に、個別支援計画の草案を作成。日々の活動計画も、狙い・流れ・配慮事項つきで下書きします。
使い方　📝計画タブで児童を選ぶ → 生成 → 児発管が内容を確認・修正して確定します。
4
セーフティノート（配慮点の共有）安全
児童の名前を送るだけで、アレルギー・苦手なこと・落ち着く方法・パニック時の対応・送迎の注意が返ってきます。担当者しか知らない状態をなくし、ヘルプや臨時の職員でも安心して支援に入れます。
使い方　👥共有タブで名前を送る → 配慮点が表示されます。閲覧はログに記録されます。
5
出欠・送迎の実績管理毎日／月末
その日の出欠、開始・終了時刻、送迎（往復）をタップで記録。月末にはサービス提供実績記録票の形で表示・印刷でき、そのまま請求データにつながります。
使い方　🗓実績タブで出席／欠席を選ぶ → 送迎にチェック → 月末に「実績記録票を表示」→ 印刷。
6
加算・返戻の事前チェック月末
個別支援計画の未作成、モニタリング期限、受給者証の期限切れ、契約支給量の超過など、減算・返戻につながる点をAIが点検します。「請求してから返戻で気づく」をなくします。
使い方　✅加算タブで児童を選ぶ → チェックを実行 → ⛔と⚠️の項目を月末までに解消。

ALL-IN-ONE / 記録から請求まで

実績も請求も、このアプリで

「記録は記録ソフト、請求は請求ソフト」で月末に転記していませんか。 そだちノートは日々の記録がそのまま実績になり、国保連への請求データまでつながる設計です。

返戻・過誤の管理返戻データを取り込み、原因（期限切れ・支給量超過等）を自動で特定本番対応
💡 返戻は「請求してから」ではなく「入力するとき」に防ぐ
  • 受給者証の有効期限が近づくと、加算チェックでお知らせします
  • 契約支給量を超えて利用日数が入ると、その場で警告します
  • 計画の未作成・モニタリング期限も同じ画面でまとめて点検できます

請求データの項目定義は、厚生労働省が公開するインタフェース仕様書の最新版に合わせて確定します。導入時には御事業所のサービス種別・自治体の様式に合わせて調整します。

GET STARTED / 導入について

導入はかんたん

アプリのインストールは不要です。スマホやパソコンのブラウザで開くだけ。 現場ではスマホ、事務所ではパソコンの大きい画面で、同じように使えます。

📱 用意していただくもの
  • スマートフォンまたはタブレット（Chrome / Safari / Edge）
  • 事務作業用のパソコン（あればより快適です）
  • 特別な機器・サーバの購入は不要です
🔒 個人情報のお取り扱い
  • 職員ごとのログイン・役職別の権限・閲覧ログを備えます
  • 通信・保存データは暗号化し、国内で管理します
  • お預かりした情報をAIの学習に使うことはありません
  • 退職された方のアクセスは即時に遮断できます
📋 まずは体験（デモ）から
  • 実際の画面を触れるデモをご用意しています。記録から実績・請求まで一連の流れを体験できます
  • 御事業所の業務フローに合うか、時短効果がどれくらいかを一緒に確認しましょう
  • ご要望に合わせて、対応する加算や様式を調整します
