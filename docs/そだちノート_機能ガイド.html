ABOUT / できること

そだちノートとは

放課後等デイサービスの「毎日の記録」「保護者への報告」「個別支援計画」「加算の書類」—— 時間のかかる書類業務を、AIがまるごと下書き・チェックします。スタッフが子どもと向き合う時間を取り戻すためのツールです。

⏱️
残業を減らす
記録・報告文の作成時間を大幅に短縮。閉所後の書類残業から解放。
💰
加算を守る
算定漏れ・減算リスクをAIが点検。事業所の収益を取りこぼさない。
✨
品質をそろえる
経験の浅いスタッフでも、AIの下書きで一定水準の記録が書ける。
FEATURES / 主な機能

4つの機能

1
音声で活動記録毎日
スマホに向かって今日の様子を話すだけ。AIが活動記録のフォーマット（活動内容・様子・支援のねらい・引き継ぎ）に自動で整形します。
使い方　児童と活動を選ぶ → 🎤ボタンを押して話す → 「AIで整形」→ 内容を確認して保存。手書き・タイピングは不要です。
2
保護者への報告文を自動生成毎日
その日の記録から、保護者向けのやわらかい報告文をワンタップで作成。トーン（ていねい／あたたかめ／簡潔）も選べます。
使い方　記録を選ぶ → トーンを選ぶ → 「報告文を生成」→ 内容を確認・編集してから送信。連絡帳アプリ／LINE連携も想定。

3
個別支援計画の下書き6ヶ月ごと
アセスメント（保護者・本人の願い）と直近の活動記録から、長期・短期目標や支援内容の「たたき台」を生成。ゼロから書く負担をなくします。
使い方　児童を選ぶ → 願い・特性を入力 → 「下書きを生成」。最終版は児童発達支援管理責任者が仕上げます。
4
加算・書類チェック収益を守る
記録・計画の状況を突き合わせ、個別支援計画の未作成（減算リスク）、モニタリング期限の超過、加算の取りこぼしをAIが点検・アラートします。
使い方　児童を選んで「チェックを実行」。要対応・確認推奨の項目が一覧で表示され、実地指導への備えにもなります。

🔒 安心してお使いいただくために
  • 児童の情報は暗号化して保管。AIの学習には利用しません（オプトアウト前提）。
  • AIが作るのは「下書き」。記録・報告・計画は必ず人が確認・承認してから確定・送信します。
  • 「誰がいつ編集したか」の履歴を保持し、実地指導（監査）にも備えます。
  • 制度改定に合わせて加算要件をアップデートしていきます。

※ 音声入力はブラウザの音声認識機能を利用します（Chrome / Edge / Safari 推奨）。専門用語は選択式にすることで認識精度を高めています。
