# 請求機能 要件一覧（介護保険／訪問介護）

かけはしノートに実装した、加算・減算を考慮した請求計算の仕様です。障害福祉（そだちノート）とは制度がまったく別のため、別ドキュメントとして整理しています。

作成日: 2026-08-15 / 対象: かけはしノート（訪問介護費）

---

## 1. 障害福祉との違い（実装を分けた理由）

| | そだちノート（障害児通所） | かけはしノート（訪問介護） |
|---|---|---|
| 制度 | 障害者総合支援法・児童福祉法 | 介護保険法 |
| 単位の決まり方 | 1日あたり（基本報酬＋加算） | **1回の訪問ごと**（区分×所要時間） |
| 利用者負担 | 原則1割＋**負担上限月額**で頭打ち | **1〜3割**（負担割合証）。上限は高額介護サービス費で市町村が処理 |
| 上限の管理 | 事業所間で**上限額管理**が必要 | **区分支給限度基準額**を超えた分は全額自己負担 |
| 主な減算 | 計画未作成減算など | **同一建物減算・虐待防止措置未実施・BCP未策定** |

## 2. 基本報酬（サービス区分×所要時間）

報告の入力時に選んだサービス区分と、開始〜終了時刻から所要時間を出して単位を決定します。

**時間区分そのものをマスタで持ちます**（何分〜何分 → 単位数）。改定で区分の切り方が変わっても、行の編集だけで対応できます。

| 区分 | 時間 | マスタコード |
|---|---|---|
| 身体介護 | 20分未満／20分以上30分未満／30分以上1時間未満／1時間以上 | 111111〜111114 |
| 身体介護 1時間30分以降30分ごと | 開始分数と刻み幅もマスタ指定 | 111115 |
| 身体介護に引き続く生活援助 | 生活援助の所要時間20分ごと（上限もマスタ指定） | 111201 |
| 生活援助 | 20分以上45分未満／45分以上（**20分未満は算定外**） | 112111・112112 |
| 通院等乗降介助 | 1回につき | 114001 |

「身体介護＋生活援助」を選んだ場合は、報告画面の「うち生活援助の時間（分）」を差し引いた分を身体介護として算定します。

## 3. 加算

| 加算 | 扱い | 実装 |
|---|---|---|
| **2人の介護員等による場合** | 訪問ごとに ×2 | ✅ 報告のチェックで |
| **夜間・早朝加算（＋25％）** | 18〜22時／6〜8時。開始時刻から自動判定 | ✅ 自動 |
| **深夜加算（＋50％）** | 22〜6時。開始時刻から自動判定 | ✅ 自動 |
| **緊急時訪問介護加算** | 1回につき（単位） | ✅ 報告のチェックで |
| **初回加算** | 月1回。その利用者の初回訪問がある月に自動付与 | ✅ 自動 |
| **特定事業所加算** | 区分Ⅰ＋20％／Ⅱ・Ⅲ＋10％／Ⅳ＋3％（率） | ✅ 事業所設定 |
| **特別地域訪問介護加算（＋15％）／小規模事業所加算（＋10％）／中山間地域等提供加算（＋5％）** | 率 | ✅ 事業所設定 |
| **介護職員等処遇改善加算** | 総単位数に対する率。**最後に適用** | ✅ 事業所設定（率を入力） |
| 認知症専門ケア加算(Ⅰ)・口腔連携強化加算 | 単位 | ✅ マスタ収録済み（既定OFF。⚙️設定でONに） |
| その他の加算（生活機能向上連携加算 等） | 単位／率 | ✅ **マスタに行を追加するだけで算定可能**（コード改修不要） |

## 4. 減算

| 減算 | 率 | 実装 |
|---|---|---|
| **同一敷地内建物等に居住する利用者** | −10％（所定単位数×90/100） | ✅ 利用者ごとに設定（率の行が利用者設定を参照） |
| **同一建物に居住する利用者が50人以上** | −15％（×85/100） | ✅ 利用者ごとに設定 |
| **同一建物等の利用者が全体の90％以上**（2024年度新設） | −12％（×88/100） | ✅ 利用者ごとに設定 |
| **高齢者虐待防止措置未実施減算** | −1％ | ✅ 事業所設定 |
| **業務継続計画未策定減算** | −1％ | ✅ 事業所設定 |

## 5. 計算の適用順（実装した順序）

```
① 訪問ごとの基本単位数（区分 × 所要時間）
② × 2人対応（×2） → × 時間帯加算（早朝・夜間 ×1.25 ／ 深夜 ×1.5）
③ 月合計に 同一建物減算（×90 ／ ×85 ／ ×88 ％）
④ ＋ 回数・月次の加算（緊急時訪問介護加算 × 回数、初回加算）
⑤ ＋ 特定事業所加算（率）／ 地域加算（率）
⑥ − 高齢者虐待防止措置未実施減算（−1％）／ 業務継続計画未策定減算（−1％）
⑦ ＋ 処遇改善加算（率）※最後
⑧ 総単位数 × 単位単価（地域区分）＝ 総費用額
⑨ 区分支給限度基準額との比較 → 超過分は全額自己負担
⑩ 自己負担 ＝ 保険内 × 負担割合（1〜3割）＋ 超過分の全額
   保険請求額 ＝ 総費用額 − 自己負担
```

**率の適用順はマスタの「順」欄で変更できます**（同一建物30 → 特定事業所50 → 地域55 → 虐待70 → BCP71 → 処遇改善90）。告示の算定構造に合わせて並べ替えてください。

> ⚠️ この適用順は検証版の既定値です。正式な算定構造での順序（特に率加算どうしの前後関係）は、最新の告示・算定構造をご確認ください。

## 6. 区分支給限度基準額（単位／月）

| 要支援1 | 要支援2 | 要介護1 | 要介護2 | 要介護3 | 要介護4 | 要介護5 |
|---|---|---|---|---|---|---|
| 5,032 | 10,531 | 16,765 | 19,705 | 27,048 | 30,938 | 36,217 |

超過した場合は請求前チェックで警告し、超過分を全額自己負担として明細に分けて表示します。**限度額もマスタ化**しており、⚙️設定で改定版ごとに編集できます。

## 7. 請求前チェック

- ⛔ 事業所情報／被保険者番号の未登録
- ⚠️ 区分支給限度基準額の超過（超過単位数と自己負担額を明示）
- ⚠️ 算定できない訪問（生活援助20分未満など）
- ⚠️ 特定事業所加算を算定設定しているが体制要件が未充足
- ⚠️ 虐待防止措置未実施減算・業務継続計画未策定減算が適用中

## 8. 未実装（本番開発項目）

1. **単位数の正式値への差し替え** — コード体系は6桁に整備済み。時間区分・単位数の**値**を告示のサービスコード表に合わせる（マスタは適用年月つきの「改定版」で管理済み。[`制度改定への対応方針.md`](制度改定への対応方針.md) 参照）
2. 算定条件が複雑な加算（有資格者の同行が要件のもの、併算定不可の判定など）
3. 居宅介護支援事業所（ケアマネ）との給付管理票の連携
4. 利用者への請求書・領収書発行、実費（交通費等）、入金管理
5. 国保連への伝送・返戻データの取込
6. 月遅れ請求・過誤申立
