# そだちノート ─ 放課後デイサービスの記録・共有AI(企画書 v0.3)

> 放課後等デイサービス向けに、**「話す/送るだけで貯まる記録」から書類・報告・計画を自動生成**し、**セーフティノートで誰もが安心して支援に入れる**ようにするサービス。

作成日: 2026-07-22 / 更新: 2026-07-30(v0.3: 訪問介護を別プロダクト「かけはしノート」として分離) / ステータス: 企画ドラフト

---

## 1. 背景と課題

| 現場の痛み | 具体的な状況 |
|---|---|
| 毎日の記録が重い | 児童ごとの活動記録を閉所後にまとめて入力。記憶が薄れ、残業になる |
| 保護者への報告が手間 | 連絡帳・アプリで一人ひとりに文章を作成 |
| 個別支援計画・活動計画 | 6ヶ月ごとの計画に加え、日々の活動計画・狙いの言語化も負担 |
| **担当者しか子どもの情報を知らない** | **臨時対応・ヘルプ勤務時に配慮点が分からず、事故・トラブルのリスク。スタッフの不安も大きい** |
| 加算申請書類の不備 | 算定要件の根拠記録の抜けが、実地指導で返還リスクに |

**本質**: 記録は「その場で断片的に発生」するのに、書類は「あとでまとまった文章」を要求される。このギャップを人が埋めているのが残業と負担の正体。

## 2. コンセプト

> **「その場では、送るだけ。書類は、ボタン一発。」**
> **「名前を入れれば、配慮点がわかる。誰でも安心して支援に入れる。」**

```
[現場・その場]                       [あとで・ボタン一発]
 音声で話す ──┐
              ├─→ 児童ごとに時系列 ──→ AIが各種書類に自動生成
 LINEにキーワード┘    ストック            (記録・報告・計画…)
 を送る
```

## 3. 機能

| 機能 | 内容 | フェーズ |
|---|---|---|
| 活動記録の自動生成 | ストックしたキーワード/音声から記録フォーマットに整形 | 1 (MVP) |
| 保護者報告の自動生成 | 記録から保護者向けトーンでリライト | 1 (MVP) |
| **セーフティノート** | **LINEで「○○くん」→ アレルギー・苦手・落ち着く方法・パニック時対応・送迎注意が即返信** | **1 (MVP・目玉)** |
| 個別支援計画の下書き | 蓄積された記録を根拠に草案を生成(児発管が確定) | 2 |
| 活動計画・狙いの下書き | 狙い・流れ・配慮事項・評価の視点を下書き | 2 |
| 加算・書類チェック | 計画未作成減算・モニタリング期限・算定漏れを点検 | 2 |

### セーフティノート(差別化の核)
「担当者しか知らない」をなくす、**時短ではなく安全のための機能**。
- 児童ごとの構造化ナレッジ(アレルギー・服薬/苦手な刺激/落ち着く方法/パニック時対応/送迎注意/申し送り)
- 日々の記録から「最近の変化」も反映
- 効果: 事故予防 / ヘルプ・新人の心理的安全 / 属人化解消 / 保護者への説明責任

**絶対条件(セキュリティ)**: アクセス権限管理(LINE利用時は職員個人認証)/ 閲覧ログ全件記録 / 退職者の即時遮断 / 暗号化・国内リージョン / AIへの学習利用なし

## 4. 提供価値

| 価値 | 中身 |
|---|---|
| ⏱ 時短 | 記録・報告・計画作成の時間を大幅削減。残業削減→離職防止 |

| 💰 増収・損失防止 | 加算算定漏れ防止・減算アラート |

訴求軸: 「時短ツール」ではなく**「安全と、お金と、監査を守るツール」**。

## 5. 技術構成

```
[入口] LINE公式アカウント(Messaging API) / Webアプリ(音声: Web Speech API)
[サーバ] 認証・権限 / ストック保存 / 生成API中継 / 閲覧ログ
[AI] Claude API(記録・報告: Haiku/Sonnet、計画: Sonnet/Opus。キャッシュで入力コスト最大約90%減)
[データ] 児童マスタ・記録・計画・ナレッジ・加算要件(編集履歴・閲覧ログ保持)
```

- AI原価試算: 児童20名規模で**月約300〜1,500円/事業所**。サブスク料金に対し原価はごく小さい
- ※ 訪問介護向け「かけはしノート」とはAIエンジン・基盤を社内で共通化し開発効率を確保(プロダクト・契約・データは顧客ごとに完全分離)

## 6. 検証KPI / リスク

- 記録1件あたりの作成時間 / 報告リードタイム / **臨時対応時の情報参照率・スタッフ安心度** / 残業時間
- リスク対応: 個人情報(権限・ログ・遮断・暗号化) / LINEなりすまし(個人認証・返信は要点のみ) / AI誤生成(人の承認必須) / 制度改定(要件をデータ化)
