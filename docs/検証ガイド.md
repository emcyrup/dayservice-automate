# 現場検証ガイド(そだちノート / かけはしノート 検証版)

協力事業所のみなさまに、検証版アプリを1〜2週間お試しいただくためのガイドです。

## アクセス方法

| アプリ | 対象 | URL |
|---|---|---|
| 🌱 そだちノート | 放課後等デイサービス | https://emcyrup.github.io/dayservice-automate/ |
| 🧡 かけはしノート | 訪問介護 | https://emcyrup.github.io/dayservice-automate/houmon/ |

- スマホの **Chrome / Safari / Edge** で開いてください(音声入力対応)
- ホーム画面に追加(ブックマーク)しておくとアプリのように使えます

## ⚠️ 検証時のお願い(重要)

1. **実名は入力しないでください。** 児童・利用者は必ずイニシャルや仮名(例: Aくん、Bさん)で登録してください。検証版は認証・暗号化のない試用環境です。
2. データは**お使いの端末のブラウザ内にのみ**保存されます(サーバには送信されません)。
   - 端末やブラウザを変えるとデータは共有されません
   - ブラウザの履歴削除でデータが消えることがあります → **⚙️設定→バックアップ** を週1回程度お願いします
3. **AIの生成文はデモ用の簡易版**です。本番はClaude(生成AI)による自然な文章になります。今回の検証では「この流れ・操作感が業務に合うか」を見てください。

## はじめに(初期設定・5分)

1. 右上の **⚙️(設定)** を開く
2. 「🧹 サンプルを削除」でデモデータを消す
3. **事業所情報**(事業所番号・事業所名・市町村/保険者番号)を登録 ― 実績記録票・請求データの検証に使います(仮の番号で構いません)
4. **👦児童タブ(かけはしノートは🏡利用者タブ)** の「＋ 追加」から、実際の児童/利用者を**仮名で**数名登録
   - 一覧の各行にある「編集」からいつでも修正できます
   - そだちノートは**セーフティノート情報**(アレルギー・苦手・落ち着く方法・パニック時対応・送迎注意)もぜひ入力してください ― 👥共有タブの検証に必要です

| # | シナリオ | 見ていただきたい点 |
|---|---|---|
| 1 | 活動中、💬記録タブでキーワードを2〜3個送る(1日数回) | その場の数秒メモが負担にならないか |
| 2 | 閉所後「貯めたメモから記録を生成」→ 保存 | 記録作成が何分短くなるか |
| 3 | ✉️報告タブで保護者向け文章を生成 | トーン・内容は使えそうか |
| 4 | 👥共有タブで児童名を送る(特にヘルプ・臨時の場面を想定) | 臨時対応に必要な情報が揃っているか。項目の過不足 |

| 6 | 🗓実績タブで毎日の出欠・送迎を記録 → 月末に「実績記録票を表示」→ 印刷 | **今お使いの実績記録票と項目が合っているか**。この入力なら毎日続けられるか |
| 7 | ✅加算タブで受給者証の期限・支給量超過の警告を確認 | 返戻の予防として役に立つか |
| 8 | ⚙️設定で単位単価・体制加算・単位数マスタを実際の値に更新 → 💴請求タブで「集計する」 | **金額が実際の請求額と一致するか**(ここが最重要) |
| 9 | 💴請求タブの請求前チェック・給付費明細書・上限額管理結果票を確認 | いま使っている請求ソフトの代わりになりそうか。足りない項目は何か |

## 記録していただきたいこと(効果測定)

できる範囲で構いません:

- **Before**: 現在の記録/報告にかかっている時間(1件あたり・1日あたり)
- **After**: アプリ使用時の時間
- 「使わなくなった機能」とその理由(最重要のフィードバックです)

## フィードバックをお聞かせください

検証後に伺いたいこと:

1. 毎日使えそうな機能・使わない機能はどれか(理由も)
2. 生成された文章は、修正なしで使えるレベルまであと何が必要か
3. セーフティノート(放デイ): 項目の過不足、臨時対応で実際に役立ったか
4. 報告3形態(訪問介護): 実際の書式・ケアピア入力と項目が合っているか
5. 「これがあれば導入したい」と思う条件(機能・価格・セキュリティ)

## 検証版の制限事項(本番との違い)

| 項目 | 検証版 | 本番(予定) |
|---|---|---|
| AI生成 | デモ用の簡易生成 | Claude APIによる自然な文章生成 |
| データ保存 | 端末内のみ | 暗号化クラウドDB・事業所内で共有 |
| ログイン・権限 | なし(→実名禁止) | 職員認証・役職別の権限・閲覧ログ |
| LINE連携 | なし(アプリ内で体験) | LINE公式アカウントから送信・照会 |
| 記録アプリ連携 | コピー機能まで | 移行期のみAPI/CSV連携(以後はアプリ内で完結) |
| 国保連請求 | 金額計算・明細書・上限額管理・請求前チェック・試作CSVまで | 様式準拠の請求データ作成→電子請求受付システムへ伝送→返戻管理 |
| 単位数 | **暫定値**(⚙️設定で編集可能) | 報酬改定に合わせたマスタ配信 |
