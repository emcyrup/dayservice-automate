# かけはしノート ─ 訪問介護の報告AI(企画書 v0.1)

> 訪問介護事業所向けに、**一度の入力から「正式報告書・記録アプリ入力用・サ責向け要約」の3形態を同時生成**し、移動記録・買い物支援の手間も減らすサービス。

作成日: 2026-07-30 / ステータス: 企画ドラフト
(放課後デイ向け「そだちノート」とは別顧客・別プロダクト。AIエンジン・基盤のみ社内共通)

---

## 1. 背景と課題

| 現場の痛み | 具体的な状況 |
|---|---|
| **報告の三重入力** | ①手書きの報告書 ②記録アプリ(例: ケアピア)への入力 ③サービス提供責任者への口頭/要約報告 ― 同じ内容(支援内容・様子・日時・支援者の体調)を3回作っている |
| 移動記録が手間 | 支援時の移動ごとに走行距離・メーター値・所要時間を報告。買い物支援があると移動・報告回数がさらに増える |
| 買い物支援の非効率 | 利用者が買ってほしい物を選ぶのに時間がかかる |

## 2. コンセプト

> **「一度話せば、3つの報告ができている。」**

```
[現場・支援後すぐ]                    [自動生成(3形態同時)]
 音声で話す or ─→ AIが整形 ─┬─→ ① 正式報告書(手書き代替)
 一言メモを送る              ├─→ ② 記録アプリ入力用(ケアピア等)
                             └─→ ③ サ責向け要約
```

## 3. 機能

| 機能 | 内容 | フェーズ |
|---|---|---|
| **報告の一本化** | 一度の入力(音声可)→ 3形態を同時生成。確認してから提出・入力 | 1 (MVP・目玉) |
| 移動記録の簡易化 | 開始/終了メーターから走行距離を自動計算。音声入力対応。履歴一覧 | 1 |
| 買い物支援の効率化 | 過去の依頼履歴をワンタップ候補+購入周期からAIが提案(「そろそろ牛乳では?」)。**確定は必ず本人・支援者** | 2 |
| 記録アプリ連携 | ケアピア等とAPI連携(提供があれば)/なければCSV・コピペ運用から開始 | 2〜3 |
| サ責ダッシュボード | 要約が自動で集まる一覧。気になる特記事項のアラート | 3 |

## 4. 提供価値

| 価値 | 中身 |
|---|---|
| ⏱ 時短 | 三重入力を1回に。移動報告もその場で数秒 |
| 🧡 質の向上 | 記憶が新しいうちに記録→報告の質が上がる。特記事項の見落とし防止 |
| 🤝 サ責の把握力 | 要約が自動で届き、全利用者の状況把握が容易に |
| ✨ 均質化 | 経験によらず一定水準の報告文 |

## 5. 技術構成

```
[入口] スマホWebアプリ(音声: Web Speech API)/ 将来: LINE入力
[サーバ] 認証 / 保存 / 生成API中継
[AI] Claude API(報告3形態の生成: Haiku/Sonnet ― 1件あたり約0.3〜1円)
[データ] 利用者マスタ・報告・移動記録・買い物履歴(編集履歴保持)
[連携] 記録アプリ(API or CSV)/ 走行距離は将来 車載・スマホGPS連携も検討
```

- AI原価試算: 1日20件の報告でも**月数百円/事業所**規模
- 利用者の個人情報(要配慮情報)を扱うため、暗号化・アクセス権限・学習オプトアウトは必須

## 6. 検証KPI / リスク

- 報告3形態の作成時間 Before/After / 移動記録の入力時間 / 買い物の品選び時間
- リスク対応: AI誤生成(人の確認後に提出)/ 誤発注(AIは提案のみ・本人確認必須)/ 記録アプリ連携不可(CSV・コピペでも価値が出る3形態同時生成)/ 数字の音声誤認識(メーターは差分自動計算・確認表示)
