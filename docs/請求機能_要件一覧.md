# 請求機能 要件一覧（障害福祉／放課後等デイサービス）

「わかるくん」「LITALICO系（はぐめいと等）」など既存の障害福祉向け請求ソフトを参考に、請求業務に必要な項目を洗い出し、そだちノートへの実装状況を整理したものです。

作成日: 2026-08-15 / 対象: そだちノート（障害児通所給付費）

---

## 0. 参考にした製品と、そこから読み取った要件

| 製品 | 位置づけ | 押さえるべき点 |
|---|---|---|
| **わかるくん**（NPO法人生活支援センター207） | 障害者総合支援法・児童福祉法対応の管理請求ソフト（フリー版あり） | 国保連伝送のために「簡易入力システムの習得」を利用者に強いない。**請求明細書・サービス提供実績記録票・利用者負担上限額管理結果票の3点セット**を作れることが最低要件 |
| **LITALICO系（はぐめいと 等）** | 放デイ・児発向けの業務支援＋請求 | 記録・支援計画と請求が地続き。上限額管理の事務フロー（翌月3日までに利用者負担額一覧表、6日までに管理結果票の送付）を運用ごと支える |

→ **請求ソフトの本体は「実績→金額計算→3帳票→伝送」**。そだちノートは記録・計画をすでに持っているため、ここに金額計算と帳票を足せば一気通貫になります。

## 1. 洗い出した必要項目

### A. 事業所マスタ
| 項目 | 用途 | 実装 |
|---|---|---|
| 事業所番号（10桁）／事業所名 | 請求データ・帳票の送付元 | ✅ |
| 所在地市町村番号 | 請求先の特定 | ✅ |
| サービス種別 | 放デイ／児発／保育所等訪問 | ✅ |
| **単位単価（地域区分）** | 単位数→円の換算 | ✅ |
| **事業所体制による加算** | 児童指導員等加配・専門的支援体制・福祉専門職員配置等 | ✅ |
| **処遇改善加算（率）** | 総単位数への率加算 | ✅ |
| 定員区分・主たる対象障害 | 基本報酬の区分決定 | ⛔ 本番（現状は単位数マスタ側で吸収） |

### B. 受給者（児童）台帳
| 項目 | 用途 | 実装 |
|---|---|---|
| 受給者証番号 | 請求のキー | ✅ |
| 支給決定障害児氏名 | 帳票表記 | ✅ |
| 契約支給量（日／月） | 支給量超過チェック | ✅ |
| 受給者証の有効期限 | 期限切れチェック | ✅ |
| **負担上限月額**（0／4,600／37,200円） | 利用者負担の頭打ち | ✅ |
| **上限額管理の区分**（対象外／自事業所が管理／他事業所が管理） | 管理結果票の要否 | ✅ |
| 上限額管理事業所番号 | 管理結果票の相手先 | ✅ |
| 支給決定期間・契約日 | 期間外請求の防止 | ⛔ 本番（有効期限で代替中） |

### C. 日々の実績（サービス提供実績記録票の元データ）
| 項目 | 実装 |
|---|---|
| 提供日・サービス提供の状況（提供／欠席） | ✅ |
| 開始時刻・終了時刻 | ✅ |
| 送迎加算（往／復） | ✅ |
| 欠席時対応加算（月4回まで） | ✅ 上限4回で自動打ち切り |
| 家庭連携加算・事業所内相談支援加算・個別サポート加算 | ⛔ 本番（マスタには追加可能な構造） |
| 保護者確認印欄 | ✅ 印刷様式に枠あり |

### D. 金額計算（請求の中核）
実装した計算式は次のとおりです。

```
① 単位数   = Σ(基本報酬 + 体制加算 + 送迎 + 欠席時対応) ＋ 処遇改善(率)
② 総費用額 = 単位数 × 単位単価           （円未満切り捨て）
③ 給付費   = 総費用額 × 給付率90%        （＝利用者負担は1割）
④ 上限調整 = min(利用者負担1割, 負担上限月額)
⑤ 上限額管理 → 決定利用者負担額
⑥ 請求額(国保連) = 総費用額 − 決定利用者負担額
```

### E. 上限額管理（複数事業所の利用）
管理結果は3区分。実装済みの判定ロジックは次のとおりです。

| コード | 意味 | 判定条件 |
|---|---|---|
| **1** | 管理事業所で利用者負担額を充当したため、他事業所の利用者負担は発生しない | 自事業所の負担額だけで負担上限月額に達する |
| **2** | 合算額が負担上限月額以下のため、調整事務は行わない | 全事業所の負担額合計 ≤ 上限月額 |
| **3** | 合算額が負担上限月額を超過するため、調整した | 上記以外。上限額を順次充当して各事業所の負担額を決定 |

他事業所の総費用額・利用者負担額を入力すると、合計・管理結果コード・調整後の負担額を自動で算出し、明細書の「決定利用者負担額」に反映します。

### F. 出力帳票
| 帳票 | 実装 |
|---|---|
| サービス提供実績記録票 | ✅ 様式表示・A4印刷 |
| 障害児通所給付費 明細書 | ✅ 画面プレビュー |
| 請求書（事業所単位の合計） | ✅ 請求サマリーとして実装 |
| 利用者負担上限額管理結果票 | ✅ 画面で作成・確定 |
| 利用者負担額一覧表（関係事業所→管理事業所） | ⛔ 本番 |
| 国保連請求データ（CSV） | ✅ 3レコード構成の試作（項目定義は仕様書突合待ち） |

### G. 請求前チェック（返戻の予防）
実装済みの点検項目:

- ⛔ 事業所情報の未登録／受給者証番号の未登録
- ⛔ 受給者証の期限切れ（対象月時点）
- ⛔ 契約支給量の超過
- ⚠️ 上限額管理結果の未作成・未入力
- ⚠️ 個別支援計画の未作成（未作成減算）
- ⚠️ 単位単価の未設定

### H. 未実装（本番開発項目）
1. **単位数マスタの正式化** — 現在の初期値は暫定。定員規模・時間区分・平日/休日で分かれる基本報酬を、告示に沿って正式なサービスコード体系で持つ
2. 利用者請求（自己負担分の請求書・領収書発行、実費項目、入金管理）
3. 国保連への伝送・返戻データの取込
4. 利用者負担額一覧表の作成・送付
5. 支給決定期間による期間外チェック
6. 多機能型事業所（児発＋放デイ）の按分

## 2. 単位数マスタについて（重要）

アプリに内蔵している単位数は**暫定値**です。報酬改定のたびに変わるため、⚙️設定の「単位数マスタ」で編集できる形にしています。導入時には最新の告示・単位数表に合わせて必ず更新してください。

現在マスタに持っている項目: 基本報酬（平日／休日）、児童指導員等加配加算、専門的支援体制加算、福祉専門職員配置等加算、送迎加算（片道）、欠席時対応加算。
