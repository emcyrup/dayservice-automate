ABOUT / できること

かけはしノートとは

手書きの報告書、記録アプリへの入力、サービス提供責任者への報告—— 同じ内容を3回書いていませんか。かけはしノートは一度の入力から3つの報告を同時に作り、 そのまま月次の実績・国保連への請求までつなげます。

⏱️
三重入力を1回に
支援後に一度話すだけ。3つの形式の報告が同時にできあがります。
💰
加算を取りこぼさない
特定事業所加算の要件を毎月自動チェック。最大＋20％を守ります。
🗂️
月末の転記をゼロに
報告がそのまま実績になり、請求データまでつながります。
FEATURES / 主な機能

5つの機能

1
一度の入力から3つの報告毎回
支援の後に一言話すか書くだけで、①正式報告書 ②記録アプリ入力用 ③サ責向け要約を同時に作成します。記憶が新しいうちに残せるので、報告の質も上がります。
使い方　📋報告タブで利用者・時刻を選ぶ → 🎤で様子を話す → 「3つの報告を生成」→ 確認してコピー・保存。
2
移動記録を数秒で移動のたび
開始と終了のメーター値を入れるだけで走行距離を自動計算。「開始12345 終了12352 15分 買い物」のように音声でまとめて入力もできます。
使い方　🚗移動タブで🎤を押して数字を話す → 自動で欄に反映 → 「記録する」。
🧡 かけはしノート サービスガイド2
3
買い物支援の時短買い物のとき
過去に頼まれた品をワンタップの候補として表示。購入の周期から「そろそろ牛乳では？」とAIが提案します。品選びの時間を短くします。
使い方　🛒買い物タブで利用者を選ぶ → 候補をタップ → 購入の確定は必ずご本人と確認してください。
4
月次実績と国保連への請求月末
日々の報告から提供回数・提供時間を自動集計。給付費明細書の作成から国保連への伝送まで、このアプリで完結させます。別の請求ソフトへの転記は不要です。
使い方　🧾実績・請求タブで対象月を選ぶ → 実績を確認 → 請求データを作成。
5
特定事業所加算の要件チェック毎月
2024年度改定の要件（体制・人材・重度者等対応）の充足状況を自動チェックし、算定できる区分を判定します。会議や健康診断の記録もアプリに残るので、実地指導の根拠になります。
使い方　🧾実績・請求タブの要件チェックで、会議の開催日・健診日などを記録 → 区分の判定が更新されます。
⭐ 特定事業所加算は、売上に直結します
  • 区分Ⅰなら＋20％、Ⅱ・Ⅲで＋10％、Ⅳで＋3％（訪問介護費に対して）
  • 要件そのものより「記録が揃っていないこと」で算定をあきらめる事業所が少なくありません
  • 会議・研修・健診の記録をアプリに残すだけで、要件の充足状況が可視化されます

ALL-IN-ONE / 報告から請求まで

報告が、そのまま請求になる

支援のたびに残した報告が、月末にはそのまま実績・請求データになります。 「記録アプリに入れて、請求ソフトにも入れる」という二重入力をなくします。

特定事業所加算の要件（2024年度改定）

要件主な内容対象区分
① 体制要件訪問介護員ごとの個別研修計画／おおむね月1回以上の会議と記録／文書での事前指示と提供後の報告／年1回以上の健康診断（事業主負担）／緊急時対応方針の明示全区分
② 人材要件介護福祉士の割合30％以上 などⅠ・Ⅱ
③ 重度者等対応重度要介護者等が20％以上 または 看取り期の対応実績（いずれか選択）Ⅰ・Ⅲ
🔍 アプリがやること
  • 会議の開催日・健康診断日を記録し、期限切れが近づくと警告します
  • 「提供後の報告」は日々の報告記録から自動でカウントします
  • 3つの要件から、算定できる区分（Ⅰ〜Ⅳ）を毎月判定します

区分の判定は目安です。実際の届出・算定にあたっては、最新の告示および自治体の手引きをご確認ください。請求データの項目定義は、厚生労働省が公開するインタフェース仕様書の最新版に合わせて確定します。

GET STARTED / 導入について

導入はかんたん

アプリのインストールは不要です。訪問先ではスマホ、事務所ではパソコンのブラウザで開くだけ。 手袋を外さずに使えるよう、音声入力を中心に設計しています。

📱 用意していただくもの
  • スマートフォン（Chrome / Safari / Edge）
  • 事務作業用のパソコン（あればより快適です）
  • 特別な機器・サーバの購入は不要です
🔒 個人情報のお取り扱い
  • 職員ごとのログイン・役職別の権限・閲覧ログを備えます
  • 通信・保存データは暗号化し、国内で管理します
  • お預かりした情報をAIの学習に使うことはありません
⚠️ AIの使い方について
  • 報告文は必ず担当者が確認してから提出・入力してください
  • 買い物の提案はあくまで候補です。購入の確定はご本人・支援者が行ってください
