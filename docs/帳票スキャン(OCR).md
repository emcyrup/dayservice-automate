# 帳票スキャン（手書き帳票の写真 → 読み取り → 他帳票へ反映）

かけはしノートに実装した、手書き帳票のOCR機能の仕様です。

作成日: 2026-08-20 / 対象: かけはしノート（訪問介護）

---

## 1. 解こうとしている問題

最初のヒアリングで挙がった痛みそのものです。

> ①手書きの報告書＋ケアピアというアプリにも入力、サービス責任者にも要約した内容を報告している

手書きは現場から完全にはなくなりません。訪問先で紙に書く、ご家族が連絡ノートに書く、他事業所から紙で届く——**紙は入口として残り続けます**。だから「紙をなくす」のではなく、**紙を撮れば以降が自動で流れる**形にしました。

```
手書き帳票を撮影 ─→ AIが読み取り ─→ 確認・修正 ─┬─→ 📋 報告（3形態を生成）
                                                 ├─→ 🚗 移動記録（距離を自動計算）
                                                 └─→ 🧬 LIFE（体重→BMI）
```

## 2. 技術的な前提（重要）

**日本語の手書きOCRは、ブラウザ内では実用になりません。** Tesseract.js等のブラウザ内OCRは活字でも日本語の精度が厳しく、手書きはほぼ読めません。

実運用は **Claude のvision機能に画像を渡し、読み取りと構造化を同時に行う** のが正解です。「この帳票から利用者名・日付・時刻・支援内容をJSONで抜き出して」と指示すれば、レイアウトが事業所ごとに違っても対応できます。従来型のOCR（文字を読むだけ）より、**帳票の意味を理解して項目に割り当てられる**点で決定的に有利です。

実装は既存の `callAI('ocr', {kind, image})` を通しており、本番は**サーバ経由のClaude呼び出しに差し替えるだけ**で動きます。検証版は画像を読まずサンプルを返し、その旨を画面に明示しています。

## 3. 実装した機能

### 3-1. 帳票の種類（4種）

| 種類 | 読み取る項目 | 反映先 |
|---|---|---|
| **訪問記録票**（手書きの報告書） | 利用者名・日付・開始/終了時刻・サービス区分・支援内容 | 📋報告 |
| **バイタル記録** | 利用者名・日付・体温・血圧(上/下)・脈拍・SpO2・体重・メモ | 🧬LIFE（体重→BMI）／📋報告 |
| **運転日報・メーター** | 日付・開始/終了メーター・所要時間・目的 | 🚗移動記録 |
| **その他のメモ** | 利用者名・日付・本文 | 📋報告 |

### 3-2. 撮影

`capture="environment"` 指定で、スマホでは**タップすると背面カメラが起動**します。撮影した画像は**長辺1280pxに縮小**してから読み取りにかけます（通信量と処理時間の削減）。

### 3-3. 確認・修正が必須の設計

OCRは必ず誤ります。読み取り結果は**そのまま反映せず、編集可能なフォームで表示**し、担当者が直してから反映する流れにしました。画面にも「必ず目視で確認してから反映してください」と明記しています。

### 3-4. 反映

反映先はチェックボックスで選べます。バイタルを📋報告に入れる場合は、数値を「体温36.4℃、血圧132/78、脈拍72、SpO2 97%」のように**文章化して**支援内容欄に追記します。利用者名からは**利用者マスタを自動で照合**します。

反映後はその帳票の画面へ自動で移動するので、確認して保存するだけです。

### 3-5. 画像を保存しない

撮影した画像は**端末にも保存しません**（読み取り後に破棄）。保存されるのは確認・修正後の項目だけです。

理由は2つあります。localStorageの容量制限（数MB）を写真で圧迫しないこと、そして**利用者の個人情報を含む写真を端末に残さない**ことです。検証版は認証がないため、後者はとくに重要です。読み取りの履歴には項目だけが残ります。

## 4. 未実装（本番開発項目）

1. **Claude vision の実接続** — `callAI('ocr')` をサーバ経由の呼び出しに差し替える。画像はサーバ経由で送り、ブラウザからAPIキーを触らせない
2. **複数枚の連続読み取り** — 1日分をまとめて撮って一括処理
3. **事業所ごとの帳票テンプレート学習** — よく使う帳票のレイアウトを登録し、読み取り精度と項目対応を安定させる
4. **読み取り信頼度の表示** — 自信のない項目をハイライトして確認を促す
5. **そだちノートへの展開** — 連絡帳・保護者からの手書きメモ・他機関からの紙資料の読み取り
6. 画像の一時保存オプション（監査対応で原本を残したい事業所向け。暗号化保存が前提）

## 5. 効果の見立て

手書き帳票1枚あたりの転記が2〜3分かかっているとすると、1日5件で10〜15分、月20日で**3〜5時間**。ここが「撮る＋確認」の30秒〜1分に置き換われば、月2〜4時間の削減になります。加えて、**転記ミスがなくなる**ことの価値は時間以上に大きいはずです（請求の返戻に直結するため）。

現場検証では、実際の帳票を撮っていただき「読み取り項目が実際の様式と合っているか」を確認するのが最重要です。
