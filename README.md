# 🌱 そだちノート ─ 放課後デイサービス業務AI（プロトタイプ）

放課後等デイサービス向けに、**日々の記録・保護者連絡・個別支援計画・加算チェック**をAIで自動化するSaaSの企画＆プロトタイプです。

## これは何？

「書類のための残業」をなくし、スタッフを子どもと向き合う時間に戻すためのツール。
音声で話すだけで活動記録が整い、保護者への報告文・支援計画の下書きが生成され、加算の取りこぼしをAIが点検します。

- 📄 企画書: [`docs/企画書.md`](docs/企画書.md)
- 🖥 プロトタイプ: [`index.html`](index.html)（ビルド不要・単一HTML）

## 動かし方

`index.html` をブラウザで開くだけです。ビルドもインストールも不要。

```bash
# どちらでもOK
open index.html            # Mac
# もしくは簡易サーバ（音声認識はhttps/ローカルホスト推奨）
python3 -m http.server 8000   # → http://localhost:8000
```

> 🎤 音声入力はブラウザ標準の Web Speech API を使用。**Chrome / Edge / Safari** 推奨。
> スマホで開くと現場での使用感を確認できます。非対応環境ではテキスト入力で試せます。

## プロトタイプでできること

| タブ | 内容 |
|---|---|
| 🏠 ホーム | 児童一覧・当日の記録数・要対応件数のダッシュボード |
| 🎤 記録 | 音声で話す → AIが活動記録フォーマットに整形して保存 |
| ✉️ 報告 | 記録から保護者向けの報告文を自動生成（送信前レビュー前提） |
| 📝 計画 | アセスメントから個別支援計画の下書きを生成 |
| ✅ 加算 | 計画未作成・モニタリング期限・加算の取りこぼしを点検 |

## 技術メモ

- フレームワークなしの静的Webアプリ（HTML/CSS/JS）。スマホファースト。
- データは `localStorage` に保存（プロト用。本番はDBへ）。
- **AI生成はデモ用の内蔵ジェネレータ**。本番は `index.html` 内の `callAI()` を
  Claude API 呼び出し（サーバ経由）に差し替えるだけで動くよう分離しています。

## 注意

AIの生成物（記録・報告・計画）は**必ず人が確認・承認してから確定/送信**する運用を前提としています。
児童の個人情報を扱うため、本番化にあたっては暗号化・アクセス管理・学習オプトアウト等のセキュリティ対応が必須です。詳細は企画書を参照してください。
