# 🌱 そだちノート ─ 福祉現場の記録・共有AI（プロトタイプ v0.2）

放課後等デイサービス・訪問介護向けに、**日々の記録・保護者連絡・支援計画・加算チェック・支援者情報共有**をAIで自動化するSaaSの企画＆プロトタイプです。

## これは何？

「その場では、送るだけ。書類は、ボタン一発。」
音声やLINE風のキーワード送信で記録の材料を貯め、AIが活動記録・保護者報告・支援計画・活動計画を下書き。名前を送るだけで配慮点がわかる**セーフティノート**で、臨時対応でも誰もが安心して支援に入れます。

- 📄 企画書: [`docs/企画書.md`](docs/企画書.md)（v0.2）
- 🖥 プロトタイプ: [`index.html`](index.html)（ビルド不要・単一HTML）
- 🌐 公開デモ: https://emcyrup.github.io/dayservice-automate/

## 動かし方

`index.html` をブラウザで開くだけです。ビルドもインストールも不要。

```bash
# どちらでもOK
open index.html            # Mac
# もしくは簡易サーバ（音声認識はhttps/ローカルホスト推奨）
python3 -m http.server 8000   # → http://localhost:8000
```

> 🎤 音声入力はブラウザ標準の Web Speech API を使用。**Chrome / Edge / Safari** 推奨。
> スマホで開くと現場での使用感を確認できます。非対応環境ではテキスト入力で試せます。

## プロトタイプでできること

| タブ | 内容 |
|---|---|
| 🏠 ホーム | 児童一覧・当日の記録数・未生成メモのダッシュボード |
| 💬 記録 | キーワードを送って貯める（LINE風）or 音声 → AIが活動記録に整形して保存 |
| ✉️ 報告 | 記録から保護者向けの報告文を自動生成（送信前レビュー前提） |
| 📝 計画 | 蓄積記録＋アセスメントから個別支援計画／活動計画・狙いの下書きを生成 |
| ✅ 加算 | 計画未作成・モニタリング期限・加算の取りこぼしを点検 |
| 👥 共有 | セーフティノート：名前を送ると配慮点（アレルギー・パニック時対応等）が返る |
| 🚗 訪問 | 訪問介護デモ：報告3形態（報告書／記録アプリ用／サ責要約）同時生成・移動記録の距離自動計算・買い物リスト時短 |

## 技術メモ

- フレームワークなしの静的Webアプリ（HTML/CSS/JS）。スマホファースト。ライト／ダークテーマ対応。
- データは `localStorage` に保存（プロト用。本番はDB＋権限管理＋閲覧ログへ）。
- **AI生成はデモ用の内蔵ジェネレータ**。本番は `index.html` 内の `callAI()` を
  Claude API 呼び出し（サーバ経由）に差し替えるだけで動くよう分離しています。
- 本番のLINE連携は LINE Messaging API を想定（キーワード送信・セーフティノート照会）。

## 注意

AIの生成物（記録・報告・計画）は**必ず人が確認・承認してから確定/送信**する運用を前提としています。
児童・利用者の個人情報を扱うため、本番化にあたっては暗号化・アクセス権限・閲覧ログ・学習オプトアウト等のセキュリティ対応が必須です。詳細は企画書を参照してください。
